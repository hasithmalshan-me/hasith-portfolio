HASITH MALSHAN — PERSONAL PORTFOLIO
====================================

FILES
- index.html : website content and sections
- style.css  : dark navy/black responsive design
- script.js  : mobile menu and scroll reveal animations
- assets/    : put your profile photo here when ready

HOW TO OPEN
1. Extract the ZIP file.
2. Open the hasith_portfolio folder.
3. Double-click index.html to open it in a browser.

BEFORE PUBLISHING
1. In index.html, replace your.email@example.com with your real email address.
2. To add your photo later:
   - Put your photo in the assets folder and name it profile.jpg.
   - In index.html, find the <div class="profile-placeholder"...> block.
   - Replace that whole block with:
     <div class="profile-placeholder">
       <img src="assets/profile.jpg" alt="Hasith Malshan" class="profile-photo">
     </div>
   - Add this to the end of style.css:
     .profile-photo { width:100%; height:100%; object-fit:cover; position:absolute; inset:0; border-radius:inherit; }
   - Remove or adjust the floating card if it overlaps your photo.

3. Update skill progress as your real skills improve. Current bars are illustrative.
4. Update the projects section when you have more projects. Do not list skills or projects you have not actually done.

FREE HOSTING
You can publish a static website with GitHub Pages or Netlify. Create an account, upload/push these files, and enable deployment. For a beginner, ask ChatGPT for step-by-step GitHub Pages publishing help.

NOTES
- This is a static front-end portfolio starter. It does not include a database or server-side features.
- Fonts are loaded from Google Fonts; if offline, fallback fonts are used.
- No private phone number, home address, or other sensitive personal details have been added.
